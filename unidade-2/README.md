# Unidade 2 — Regressão | Reveal.js

Apresentação em Reveal.js para a disciplina Aprendizagem de Máquina.

## Como executar

Abra `index.html` no navegador. É necessário acesso à internet para carregar o Reveal.js e os plugins via CDN.

## Arquivos

- `index.html`: slides da apresentação
- `css/custom.css`: identidade visual minimalista em azul/cinza/branco pastel
- `js/slides.js`: configuração do Reveal.js
- `REFERENCIAS.md`: referências bibliográficas e técnicas

## Exportar para PDF

1. Abra `index.html?print-pdf` no navegador.
2. Use `Ctrl/Cmd + P`.
3. Escolha “Salvar como PDF”.
4. Marque “gráficos de plano de fundo”.
5. Use layout horizontal/paisagem.

## Conteúdo

Cobre regressão linear simples, regressão múltipla, regressão polinomial, Ridge, Lasso, Elastic Net, métricas, análise de resíduos, colinearidade e laboratório principal com scikit-learn.
