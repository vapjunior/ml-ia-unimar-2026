AR e MA: duas memórias diferentes

Autorregressão · AR(1)

yt = c + φ yt−1 + εt

Usa valores anteriores da série.

Média móvel · MA(1)

yt = μ + εt + θ εt−1

Usa choques anteriores do modelo.

MA em ARIMA é diferente da média móvel calculada com rolling().

Um perfil e uma lista de sugestões

A pessoa já estudou os cursos 0 e 1. O protótipo retorna até 3 cursos ainda não vistos.

from sklearn.metrics.pairwise import cosine_similarity

vistos = [0, 1]
perfil = np.asarray(itens[vistos].mean(axis=0))
scores = cosine_similarity(perfil, itens).ravel()
scores[vistos] = -np.inf
ordem = np.argsort(-scores)
top = ordem[scores[ordem] > 0][:3]
recomendados = catalogo.iloc[top][["titulo"]].copy()
recomendados["similaridade"] = scores[top]
print(recomendados)

NDCG considera a posição dos acertos

DCG@K = Σj=1…K gj / log₂(j+1)
NDCG@K = DCG@K / DCG@K ideal

Com relevância binária e K=3: [1, 0, 1] tem NDCG ≈ 0,704; [1, 1, 0] tem 0,765.

Neste exemplo existem 3 itens relevantes no universo, então o ideal em K=3 é [1, 1, 1].

Métricas de ranking em código

Exemplo independente, com 6 itens e relevância binária conhecida.

from sklearn.metrics import ndcg_score

relevancia = np.array([1, 0, 1, 0, 1, 0])
pontuacao = np.array([0.9, 0.8, 0.7, 0.6, 0.5, 0.4])
k = 3
top_k = np.argsort(-pontuacao)[:k]
precision = relevancia[top_k].sum() / k
recall = relevancia[top_k].sum() / relevancia.sum()
ndcg = ndcg_score([relevancia], [pontuacao], k=k)
print(precision, recall, ndcg)
